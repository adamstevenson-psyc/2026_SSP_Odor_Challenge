# 2026_SSP_Odor_Challenge
This repository contains R code to support Adam Steveson and Rick Zepp's presentation at the 2026 Society of Sensory Professionals. This was part of a joint workshop with Sensometrics with the initial session taking place in Spain at the 2026 Sensometrics meeting. 

The challenge data set was provided by SSP. The challenge is determining how best to handle analysis of time intensity sensory panel data near the threshold of perception. In this situation, data often contains large numbers of 'zeros' when the human evaluator responds on a 0 - 15 intensity scale for various taste or olfactory attributes across several time points (i.e. temporal intensity method). As a result, the normality assumptions of the typical ANOVA approach are violated. 

This has several practical applications including masking of off-notes in the food and beverage industry.  The approach is to consider three types of analysis that answer different questions about the data and potentially complement each other. 

This is an exploratory project to contribute to the discussion and requires additional development. Several workshop participants submitted potential approaches but no complete solution or consensus among experts on approach has been discovered.
